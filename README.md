# ITSM Incident Management Using Machine Learning

## Project Overview
This project applies Machine Learning to IT Service Management (ITSM)
data to predict incident priorities and support IT incident analysis.

## Objectives
- Analyze IT incident data.
- Perform data cleaning and exploratory data analysis.
- Predict incident priority.
- Compare Logistic Regression and Random Forest models.
- Evaluate model performance.
- Generate prediction results and visualizations.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- SQLAlchemy
- MySQL
- Joblib

## Machine Learning Models
1. Logistic Regression
2. Random Forest Classifier

## Project Files
- `ITSM_Incident_Management_ML.ipynb` — Project notebook.
- `best_itsm_priority_model.pkl` — Trained model.
- `itsm_preprocessor.pkl` — Preprocessing pipeline.
- `requirements.txt` — Required Python libraries.
- `Results/` — Prediction results and evaluation outputs.
- `Reports/` — Project documentation.

## Dataset Note
The current analysis uses the first 1,000 records retrieved from the
database. Results should be validated using the complete dataset.
